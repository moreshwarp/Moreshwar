This is a component review, not a new search feature. Use the archive for functional search. All new styles use shared CSS tokens; no existing published articles were changed.

Reading must remain comfortable

Compact discovery and generous reading space are different design problems. The first screen should show useful choices. Once a reader opens an article, typography should support sustained attention.

Consistent rules

UI uses the system sans-serif stack. Headlines use a restrained editorial serif. Spacing follows shared tokens; cards and borders follow one reusable treatment.

Responsive grid: three columns on desktop, two on tablet, one on small screens. Motion respects reduced-motion settings.
