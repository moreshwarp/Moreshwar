# Moreshwar Research Lab — Review-only editorial redesign

This branch is exclusively for review and iterative UX work. **Do not merge into main or deploy without fresh, explicit user approval.**

## Approved visual direction
- Apple-like minimalism and a compact magazine homepage.
- Pure monochrome palette, unified font families and typography scale, spacing and responsive tokens across the entire site.
- Original meaningful custom illustrations; no generic stock imagery.
- Low-scroll discovery: useful first viewport, compact navigation, search and links to real published content.
- Accessible mobile and keyboard navigation, comfortable full-article reading.
- Preserve existing articles, functionality and source integrity. No fabricated content or freshness.

## Current development phase
Prioritize product UX over new test-case authoring or CI optimization. Preserve existing safety checks. Keep hourly development active. Every change stays on this review branch; preview and obtain explicit approval before deployment.

Review `studio.html` on this branch; design is not automatically approved or live.
