Machine Check

Find out what your computer is doing while you work. A 30-second reading opens a private report with graphs, plain-English explanations and suggested next steps.

Download the Python tool

Run your first check

Install Python 3.9 or newer, download the tool, then open a terminal in the folder containing the download. Pick your operating system below.

Mac or Linux
python3 -m venv machine-env
machine-env/bin/python -m pip install psutil
machine-env/bin/python machine_check.py
Windows
py -m venv machine-env
machine-env\Scripts\python.exe -m pip install psutil
machine-env\Scripts\python.exe machine_check.py

Keep doing the task you want to measure. Your browser opens the finished report. Find it again in the Machine Check folder in your home directory. Readings and app names stay on your computer.

Try a comparison

On your first run, open the project you usually work on. On the next run, do the same work after closing a large app. Add --workload development --seconds 60 to both runs for a one-minute comparison.

The report shows how processor use and free storage changed. If the processor stayed busy but the task finished quickly, that can be an efficient use of the machine. Repeated delays during ordinary work deserve a closer look.

What the readings cover

Processor and memory graphs, use by logical CPU, free space, drive and network transfer rates, battery charge when available, and the five processes using the most resident memory. Repeated readings can show OS version changes and give a conditional storage estimate.

Sensor availability depends on the operating system. Version notes are linked for manual review. A short sample cannot establish hardware failure or a long-term habit.
