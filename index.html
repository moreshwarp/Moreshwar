Computer Architecture Field Studies

Working research papers and formal investigations into hardware execution dynamics:

  • Breaking the Memory Wall — How Unified Memory Architecture (UMA) broke the discrete GPU PCIe copy bottleneck.
  • Anatomy of Apple M4 Micro-Architecture — 8-wide decode superscalar out-of-order execution and asymmetric thread scheduling.
  • The Mathematics of Mach Virtual Memory — Why "free RAM" is a myth, page replacement algorithms, and in-RAM WKdm compression.
  • Queueing Theory & Unix Load Averages — Applying Little's Law and exponentially damped moving averages to multi-core run queues.

About

I use this site to document questions, reason from evidence, and build reproducible examples. Interests include distributed systems, operating systems, concurrency, mathematical foundations and careful technical communication.
