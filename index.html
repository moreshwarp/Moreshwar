EXP / 002 · QUEUEING THEORY● LIVE MODEL

Busy is not the same as fast.

Move the arrival rate toward service capacity and inspect the predicted mean response time.

SINGLE SERVER / μ = 20 req/sM/M/1
UTILIZATION50%
MEAN RESPONSE100 ms

W = 1 / (μ − λ), for λ < μ. Ideal single-server queue with Poisson arrivals and exponential service.

EXP / 003 · REPLICATION● LIVE MODEL

What did your read actually see?

Write to one copy, pause delivery, and watch a second copy lag behind. It is a toy model of stale reads—not a consensus system.

PRIMARY / A0Latest accepted write
→ → →updates
REPLICA / B0Latest delivered write
READ FROM BUp to date

Manual delivery only. Demonstrates visible staleness; it does not implement quorum reads, leader election or agreement.
